# OneMoreWord Homework Hub

Homework site for OneMoreWord classes.

- `docs/` – the website (published by GitHub Pages)
- `docs/topics/` – one file per lesson (lesson notes, homework, answer key)
- `supabase/setup.sql` – database setup
- `supabase/functions/admin/` – teacher account tools (Supabase Edge Function)

Student logins, answers and recordings are stored in Supabase, not in this repository.
